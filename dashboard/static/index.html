First time here? Account setup & local access+

IT-Tools, CyberChef, MyIP, Gatus, and SO-CRATES are ready without an account. Gatus already monitors the toolkit.

Uptime Kuma, Snipe-IT, and ConvertX: open the tool and complete its first-run setup. Create the ConvertX account promptly: the first visitor becomes its owner.

Stirling-PDF: sign in as admin using STIRLING_ADMIN_PASSWORD from the toolkit’s private .env file. Change the password when prompted.

NetBox: create your administrator once by running this from the toolkit folder:

docker compose exec netbox /opt/netbox/netbox/manage.py createsuperuser

Availability means the web service responds. It does not verify logins or every application feature. Applications may take several minutes to initialize. Keep the host running for continuous monitoring.
